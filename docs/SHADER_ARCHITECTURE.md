# Xbox Series X|S Shader Formats & Translation Architecture in MizuBox

## 1. Empirically Verified Shader Formats (Xbox Series X|S / Scarlett)

Inspection of the real Xbox Series X|S GTA VI build (`v1.0.2.1`) revealed **four distinct shader variants** shipped inside `DXBC` containers across middleware DLLs and game archives:

| Format | Enum (`D3D12XBOX_SHADER_KIND`) | Observed In | Container Structure | Desktop D3D12 Compatibility |
|---|---|---|---|---|
| **Pure `dxil-ms-xb2` DXIL (dual-payload DXIL + FSSM)** | `XBOX_DXIL_PURE` | `XboxBvhBuilder.dll` (9 / 52 shaders, e.g. `ResetCounterValues.pdb`) | `DXBC` with `DXIL` LLVM 3.7 bitcode (`dxcxbox`, `XDAT tag 0x07` = `DXIL` + `tag 0x0d` = `XBCH/FSSM`), `RTS0` flags `0x03000000`, `0` `@xbox.*` intrinsics | **Native execution verified on RTX 5060** once external `RTS0` Xbox flags are stripped via `d3d12_xs.dll` |
| **`dxil-ms-xb2` with `@xbox.*` RDNA2 Intrinsics (dual-payload DXIL + FSSM)** | `XBOX_DXIL_INTRINSIC` | `XboxBvhBuilder.dll` (43 / 52 shaders; 32 unique `@xbox.*` ops) | `DXBC` with `DXIL` bitcode invoking proprietary RDNA2 intrinsics (`xbox.global_load/store_dword*_with_cache`, `xbox.global_atomic_*`, `xbox.s_load_dword_with_cache`, `xbox.V_CNDMASK_B32`, `xbox.Ballot64`, `xbox.TypedLoad.i32`, etc.) + embedded `XBCH/FSSM` | **Incompatible with desktop DXIL drivers**: `xbox.TypedLoad.i32` (`LeafRehydration.pdb`) fails with `E_OUTOFMEMORY`; the other 42 return `S_OK` on NVIDIA without SASS lowering and fault at `nvwgf2umx.dll+0x4AE373` during `SetPipelineState` |
| **Precompiled RDNA2 `FSSM` (`NOBC`)** | `XBOX_FSSM_RDNA2` | `shaders.rpf` (all 26,503 title shaders: VS, PS, CS, GS, Mesh) | `DXBC` whose `DXIL` chunk contains `XDAT` (`tag 0x07` = `NOBC` stub with **zero LLVM bitcode**, `tag 0x12` = 16-byte hash, `tag 0x0d` = `XBCH` zlib-compressed `FSSM` blob; RDNA2 machine code at `*(u32*)(fssm + 0xC0) + 0x28` ending in `s_endpgm` `0xBF810000`) | **Impossible to pass raw to desktop D3D12**: requires RDNA2 ISA → SPIR-V / DXIL translation |
| **Precompiled RDNA2 `ACCC` (`FSPX`)** | `XBOX_ACCC_RDNA2` | `amd_fidelityfx_upscaler_xbox.dll` (29 / 29 shaders) | `DXBC` with `ACCC` chunk (`FSPX` header + precompiled RDNA2 ISA ending in `s_endpgm`), no `DXIL` chunk | **Requires RDNA2 ISA translation** (or desktop FidelityFX SDK shader substitution) |

## 2. What Is Implemented Today in `d3d12_xs.dll` (Pure Direct3D 12)

Implemented clean-room in [d3d12_xs_shader_pipeline.h](../native/d3d12_xs_shader_pipeline.h), [d3d12_xs_sm66_runtime.h](../native/d3d12_xs_sm66_runtime.h), [d3d12_xs_rdna2_to_hlsl.h](../native/d3d12_xs_rdna2_to_hlsl.h), [wsx_inflate.h](../native/wsx_inflate.h), and [d3d12_xs.cpp](../native/d3d12_xs.cpp):

1. **Zero-dependency Shader Inspector (`D3D12XboxInspectShaderBytecode`):**
   - Classifies every incoming `D3D12_SHADER_BYTECODE` across `CreateGraphicsPipelineState`, `CreateComputePipelineState`, `CreatePipelineState` (including `AS`/`MS` mesh shader streams), and `CreateComputePipelineStateX` (`slot 0x1F0`).
   - Detects `XDAT`/`NOBC`/`XBCH`/`FSSM`, `ACCC`/`FSPX`, and LLVM 3.7 `char6` bit-packed `@xbox.*` intrinsics (`0` false positives / `0` false negatives across all 52 `XboxBvhBuilder.dll` shaders).
   - Tracks live counters in `D3D12XboxGetAbiTelemetry`.
2. **Built-in Clean-Room `XBCH → FSSM` Unpacker (`D3D12XboxUnpackShaderFssm`):**
   - Decompresses `XBCH` zlib payloads in memory with zero external DLL dependencies (`wsx_inflate.h`), locating the exact RDNA2 ISA code offset (`*(u32*)(fssm + 0xC0) + 0x28`), padded code size (`+0xC8`), Wave32/Wave64 mode (`+0xD4` bit 5), compute threadgroup dimensions `[numthreads(X,Y,Z)]` (`+0x13C..+0x144`), and `s_endpgm` (`0xBF810000`) boundary.
3. **Pure Direct3D 12 SM 6.6 Runtime Contract for Translated Xbox Shaders:**
   - **Capability probing (`D3D12XboxCheckSm66Support`):** verifies SM 6.6+ (`0x68` on RTX 5060), Resource Binding Tier 3, Dynamic Resources (`ResourceDescriptorHeap[]` / `SamplerDescriptorHeap[]`), 64-bit atomics, Mesh Shader Tier 1, and DXR Tier 1.1+ (`Tier 1.2` on RTX 5060).
   - **Standard 40-DWORD Root Signature (`D3D12XboxCreateSm66RootSignature`):** packs 32 Xbox user SGPRs (`uint4 wsx_s_vec[8]`, 128 B) + 64-bit `heap_base` + 64-bit `code_base` (`s_getpc_b64`) + slab table base/shift + FNV-1a descriptor table metadata (32 B) = 160 B (40 DWORDS, well inside D3D12's 64-DWORD limit) with `CBV_SRV_UAV_HEAP_DIRECTLY_INDEXED | SAMPLER_HEAP_DIRECTLY_INDEXED`.
   - **Reusable SM 6.6 HLSL Runtime Preamble (`D3D12XboxGetSm66HlslPreamble`):** emulates Xbox 64-bit GPU virtual addresses (`wsx_va_load32/64/128`, `wsx_va_store32/128`, `wsx_va_atomic_add32`) over a contiguous table of `RWByteAddressBuffer` slabs in `ResourceDescriptorHeap[]`, PC-relative `FSSM` constant table reads (`wsx_code_load32`), and bindless FNV-1a `T#`/`S#` descriptor lookup (`wsx_lookup_tsharp` / `wsx_lookup_ssharp`) — with **zero Vulkan or vendor extensions**.
   - **Dynamic Runtime DXC Compiler (`D3D12XboxCompileHlslToDxil`):** dynamically discovers and loads Windows SDK `dxcompiler.dll` + `dxil.dll` (`WSX_DXC_DIR`, DLL/exe dir, `PATH`, or `Windows Kits\10\bin\*\x64`) to compile translated SM 6.6 HLSL to signed desktop DXIL at runtime.
4. **Built-in Clean-Room RDNA2 (`FSSM`) → HLSL SM 6.6 → Signed DXIL Translator (`d3d12_xs_rdna2_to_hlsl.h`):**
   - **CFG-reachable BFS GFX10.3 / RDNA2 binary decoder:** covers all 14 encodings (`SOPP`, `SOPC`, `SOP1`, `SOPK`, `SOP2`, `VOP1`, `VOPC`, `VOP2`, `VOP3`, `VOP3P`, `SMEM`, `DS`, `FLAT`/`SCRATCH`/`GLOBAL`, `MUBUF`, `MTBUF`, `MIMG`, `EXP`, `VINTRP`) with exact 32/64/96-bit literal/SDWA/DPP16/DPP8/NSA word sizing and BFS CFG traversal from `pc=0`, cleanly skipping inline `s_getpc_b64` constant tables after `s_endpgm` (`0` unknown instruction encodings across all **26,503** shaders / **44,324,415** instructions in `shaders.rpf`).
   - **Full Multi-Stage GFX10.3 SM 6.6 HLSL Lifter (`ps_6_6`, `vs_6_6`, `gs_6_6`, `cs_6_6`, `as_6_6`, `ms_6_6`):** extracts CS `[numthreads(X,Y,Z)]` from `FSSM +0x13C..+0x144`, detects Wave64 vs Wave32 from `FSSM +0xD4` bit 5 (`WAVE32_EN`) + decoded `EXEC` instructions, splits basic blocks at branch leaders (`for + switch(wsx_pc)`), tracks full 64-bit `exec_lo/exec_hi` & `vcc_lo/vcc_hi` lane masks (`v_cmpx_*`, `s_*_saveexec_b64/b32`, `s_*_wrexec_b64/b32`, `v_mbcnt_lo/hi_u32_b32`) via `WaveActiveBallot` + `wsx_mask_bit` (with optional `[WaveSize(64)]` via `WSX_EMIT_WAVESIZE64=1` for 64-wide AMD GPUs), implements exact IEEE-754 `NaN` semantics across all 16 `VOPC` predicates + 10-bit `wsx_fp_class_f32`, `VOP3P` (`v_fma_mix_*`, `v_pk_*`, `v_dot*`), `SDWA`, `DPP16`/`DPP8`, `ds_swizzle_b32`, `v_permlane16_b32` with dynamic `WaveGetLaneCount()`, `v_cube*`, `v_perm_b32`, `v_movrel*`, `EXP` (`MRT0..7`, `MRTZ`, `NULL`, `POS0..3`, `PRIM`, `PARAM0..31`, `COMPR` FP16 pairs, `VM` `discard`), `VINTRP` + `VOP3Interp` (`v_interp_p1/p2/mov_f32`, `v_interp_p1ll/p1lv/p2_f16`) with contiguous `SV_Position` (Row 0) + `TEXCOORD0..N-1` (Rows `1..N`) D3D12 inter-stage signature packing, `s_getpc_b64` → `wsx_code_load32()`, `SMEM`/`MUBUF`/`MTBUF`/`GLOBAL`/`FLAT`/`SCRATCH` (sub-dword + full 32-bit atomics), stage-aware `DS` (32 KB `groupshared` in CS/AS, 8 KB `groupshared` in MS, thread-local fallback in VS/PS/GS), and `MIMG` (`wsx_lookup_tsharp` / `wsx_lookup_ssharp`).
   - **Public C API, Offline Pre-Compiler & Auto-Translation Hook:** `D3D12XboxTranslateFssmToHlslSm66`, `D3D12XboxTranslateDxbcFssmToDxil`, `wsx_rdna2_audit.exe` (with `--export-index <path.json>` metadata catalog and multithreaded resumable `--build-cache <dir> --jobs <N>` DXIL pre-warmer), and built-in `WSX_AUTO_TRANSLATE_FSSM=1` (`[Graphics] auto_translate_fssm = 1` in `wsx.ini`) auto-translation across `CreateGraphicsPipelineState`, `CreateComputePipelineState`, and `ID3D12Device2::CreatePipelineState` (Mesh/Amplification PSO streams).
   - **Full-Archive Mass Audit (`wsx_rdna2_audit.exe shaders.rpf --dxc-test-stages 10`):**
     - **All `26,503` Shaders (12,101 PS + 9,282 MS + 2,689 CS + 2,236 VS + 195 GS):** **`44,324,415 / 44,324,415` insns = `100.000%`** (`0` unimplemented, `0` unknown; **`26,503 / 26,503` shaders at `100.0%`**; `17,483` `SDWA` + `23,727` `DPP` ops in CS).

## 3. Pure Direct3D 12 Architecture for Real Title Shaders & Middleware (`backend = d3d12`)

**Primary Architecture — Pure Direct3D 12 (SM 6.6 Dynamic Resources + DXR Tier 1.1):**
- **No Vulkan required:** works natively across NVIDIA, AMD, Intel, and WARP using standard Direct3D 12 SM 6.6 + DXR Tier 1.1.
- **64-bit GPU Virtual Address Emulation (`ResourceDescriptorHeap` Slabs):** replaces Vulkan's `PhysicalStorageBuffer64` with contiguous `RWByteAddressBuffer` slabs indexed by `uint((va - heap_base) >> slab_shift)` and byte offset `uint(va - heap_base) & ((1u << slab_shift) - 1u)`. Verified bit-exact across multiple slabs on RTX 5060 with 0 D3D12 Debug Layer errors (`sm66_rdna_runtime`).
- **40-DWORD Root Constants (`b0`):** carries `s0..s31`, `heap_base`, `code_base` (for `s_getpc_b64` inline `FSSM` constants), slab metadata, and FNV-1a descriptor table metadata.
- **Bindless `T#`/`S#` Resolution:** `StructuredBuffer<WsxDescHashEntry>` in `ResourceDescriptorHeap` maps raw 8-dword `T#` / 4-dword `S#` console descriptors to desktop `ResourceDescriptorHeap[]` / `SamplerDescriptorHeap[]` indices.
- **Pure `dxil-ms-xb2` shaders:** execute natively on desktop D3D12 (`ResetCounterValues.pdb` verified bit-exact on RTX 5060).
- **Hardware DXR Tier 1.1 `XboxBvhBuilder.dll` Bridge:** clean-room drop-in replacement (`bin/XboxBvhBuilder.dll`) exporting all 12 mangled C++ symbols of Microsoft's `XboxBvhBuilder.dll` and routing BLAS/TLAS prebuild, build, batched build, and copy directly to hardware `ID3D12Device5` / `ID3D12GraphicsCommandList4` (bypassing the 43 `@xbox.*` RDNA2 compute shaders entirely).
- **Native DX12 SM 6.6 `amd_fidelityfx_upscaler_xbox.dll` Bridge:** clean-room drop-in replacement (`bin/amd_fidelityfx_upscaler_xbox.dll`) exporting all 5 FidelityFX API v2.0 C entry points (`ffxCreateContext`, `ffxDestroyContext`, `ffxConfigure`, `ffxQuery`, `ffxDispatch`) and replacing the 29 Xbox RDNA2 `ACCC/FSPX` passes with runtime-compiled SM 6.6 Lanczos-2 temporal accumulation + 3×3 YCoCg variance clipping + 5-tap RCAS sharpening + reactive mask generation — dynamically loaded by the real `amd_fidelityfx_loader_xbox.dll` and verified on RTX 5060 with `0` D3D12 Debug Layer errors.
- *(Optional secondary path)* `D3D12XboxGetGraphicsBackend` also preserves the `vulkan` selector if a user ever plugs in an external SPIR-V backend, while `d3d12` remains the default primary path.
